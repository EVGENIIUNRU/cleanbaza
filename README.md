# Контроль чистоты компьютерного клуба

Статический сайт для сменного чек-листа чистоты: дата, дневная/ночная смена, задачи по зонам, отметки выполнения, проблемы, комментарии и CSV-отчет.

Публичный адрес после деплоя GitHub Pages: https://evgeniiunru.github.io/cleanbaza/

## Быстрый запуск

1. Откройте `index.html` в браузере.
2. Выберите дату смены и `День` или `Ночь`.
3. Отмечайте задачи в списке или через правую панель.
4. При необходимости загрузите свой Excel/CSV через блок `Загрузка задач` или скачайте CSV-шаблон.

Сайт работает без сервера. Данные хранятся в браузере, пока не подключен Google Apps Script.

## Файлы

- `index.html` - интерфейс сайта.
- `styles.css` - оформление.
- `app.js` - логика смен, Excel/CSV импорта, локального хранения и синхронизации.
- `shablon_chistoty_kompyuternogo_kluba.xlsx` - Excel-шаблон задач.
- `apps-script.gs` - код для записи отметок в Google Sheets.
- `scripts/build_cleanliness_workbook.mjs` - генератор Excel-шаблона.

## Формат листа `Задачи`

Обязательные колонки:

- `ID`
- `Активна`
- `Зона`
- `Задача`
- `Описание`
- `Смена`
- `Периодичность`
- `Каждые N дней`
- `Срок/время`
- `Приоритет`
- `Фото/подтверждение`
- `Инвентарь`
- `Стандарт выполнения`
- `Дата старта`
- `Комментарий`

Поддерживаемые смены: `Дневная`, `Ночная`, `Обе`.

Поддерживаемая периодичность: `Каждая смена`, `Каждый день`, `Через день`, `Каждые 2 дня`, `Каждые 3 дня`, `Еженедельно`, `Раз в 3 недели`, `Раз в месяц`, `После каждого гостя`.

## Подключение Google Sheets

1. Создайте Google Sheets с листом `Задачи` по колонкам ниже или импортируйте локальный Excel-шаблон из этой папки.
2. В таблице откройте `Extensions -> Apps Script`.
3. Вставьте код из `apps-script.gs`.
4. Нажмите `Deploy -> New deployment -> Web app`.
5. Настройки: `Execute as: Me`, `Who has access: Anyone with the link`.
6. Скопируйте Web app URL и вставьте его в блок `Google Drive` на сайте.
7. Нажмите `Синхронизировать`.

После подключения сайт читает задачи из листа `Задачи`, а отметки смен пишет на лист `Отметки`.
