# Контроль чистоты компьютерного клуба

Статический сайт для сменного чек-листа чистоты: дата, дневная/ночная смена, задачи по зонам, отметки выполнения, проблемы, комментарии и CSV-отчет.

Публичный адрес после деплоя GitHub Pages: https://evgeniiunru.github.io/cleanbaza/

## Быстрый запуск

1. Откройте `index.html` в браузере.
2. Выберите дату смены и `День` или `Ночь`.
3. Отмечайте задачи в списке или через правую панель.
4. При необходимости загрузите свой Excel/CSV через блок `Загрузка задач` или скачайте CSV-шаблон.

Сайт работает без сервера. Данные хранятся в браузере, пока не подключен Google Apps Script.

## Windows-приложение для админ-ПК

Репозиторий также собирает desktop-приложение `BAZA Clean Ops` для Windows. Внутри используется тот же интерфейс, `app.js`, Excel/CSV-импорт и синхронизация с Google Apps Script, поэтому структура задач и логика отметок совпадают с сайтом.

### Скачать готовую сборку

1. Откройте GitHub-репозиторий `cleanbaza`.
2. Перейдите в `Actions`.
3. Откройте последний успешный запуск `Build Windows desktop app`.
4. В блоке `Artifacts` скачайте `BAZA-Clean-Ops-Windows`.
5. Распакуйте архив и запустите:
   - `BAZA Clean Ops-Setup-1.0.0-x64.exe` - установка на ПК с ярлыком.
   - `BAZA Clean Ops-Portable-1.0.0-x64.exe` - запуск без установки.

Если Windows SmartScreen предупредит о неизвестном издателе, это ожидаемо для неподписанной сборки из GitHub. Для постоянного распространения можно позже добавить code signing сертификат.

### Собрать вручную на Windows

```bash
npm install
npm run build:win
```

Готовые `.exe` появятся в папке `dist/`.

## Файлы

- `index.html` - интерфейс сайта.
- `styles.css` - оформление.
- `app.js` - логика смен, Excel/CSV импорта, локального хранения и синхронизации.
- `shablon_chistoty_kompyuternogo_kluba.xlsx` - Excel-шаблон задач.
- `apps-script.gs` - код для записи отметок в Google Sheets.
- `scripts/build_cleanliness_workbook.mjs` - генератор Excel-шаблона.
- `electron/main.cjs` - оболочка Windows-приложения.
- `.github/workflows/windows-app.yml` - сборка `.exe` через GitHub Actions.

## Формат листа `Задачи`

Обязательные колонки:

- `ID`
- `Активна`
- `Зона`
- `Задача`
- `Описание`
- `Смена`
- `Периодичность`
- `Каждые N дней`
- `Срок/время`
- `Приоритет`
- `Фото/подтверждение`
- `Инвентарь`
- `Стандарт выполнения`
- `Дата старта`
- `Комментарий`

Поддерживаемые смены: `Дневная`, `Ночная`, `Обе`.

Поддерживаемая периодичность: `Каждая смена`, `Каждый день`, `Через день`, `Каждые 2 дня`, `Каждые 3 дня`, `Еженедельно`, `Раз в 3 недели`, `Раз в месяц`, `После каждого гостя`.

## Подключение Google Sheets

1. Создайте Google Sheets с листом `Задачи` по колонкам ниже или импортируйте локальный Excel-шаблон из этой папки.
2. В таблице откройте `Extensions -> Apps Script`.
3. Вставьте код из `apps-script.gs`.
4. Нажмите `Deploy -> New deployment -> Web app`.
5. Настройки: `Execute as: Me`, `Who has access: Anyone with the link`.
6. Скопируйте Web app URL и вставьте его в блок `Google Drive` на сайте.
7. Нажмите `Синхронизировать`.

После подключения сайт читает задачи из листа `Задачи`, полный журнал пишет на лист `Отметки`, а текущую таблицу выполнения ведет на листе `Статус смены`.

Если менялся код `apps-script.gs`, вставьте новую версию в Apps Script и сделайте `Deploy -> Manage deployments -> Edit -> New version -> Deploy`. Иначе опубликованный Web app продолжит работать на старом коде.

## Часовой пояс

Сайт считает текущую смену по `Asia/Vladivostok` в `app.js`. Google Sheets получает время отметки через `apps-script.gs`, где оно принудительно форматируется в том же часовом поясе.

Чтобы изменить часовой пояс, поменяйте значение `TZ` в двух файлах:

- `app.js` - дата и определение дневной/ночной смены на сайте.
- `apps-script.gs` - время записи в листах `Отметки` и `Статус смены`.

После изменения `apps-script.gs` обязательно опубликуйте новую версию Web app в Apps Script.
